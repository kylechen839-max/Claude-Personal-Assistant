Get your own Anthropic API key

Kwil talks to Claude with an API key from Anthropic, the company that makes Claude. Your first few dollars are on a starter credit. After that you add a key of your own and pay Anthropic directly for what you use. It takes about five minutes.

What it costs

An estimate, not a price: Anthropic bills by how much text goes in and out, so longer conversations, photos and files cost more. With Kwil's default model a typical message costs about $0.02.

Steps

  1. Create an Anthropic account

    Go to console.anthropic.com and sign up with your email or Google account. This is the developer console, separate from a Claude.ai subscription.

  2. Add credit

    Open Billing (under Settings) and add credit with a card. $5 or $10 is plenty to start; Anthropic takes the cost of each message from it.

  3. Set a monthly spend limit

    Still in Settings, open Limits and set a monthly spend limit, for example $10. Once it is reached, the key stops working until the next month, so you never spend more than you chose.

  4. Create a key

    Open API keys, tap Create key, give it a name such as "Kwil" and copy it. It starts with sk-ant-. Anthropic shows it only once.

  5. Paste it into Kwil

    In Kwil, open Settings, then Connections, then Anthropic (Your API key). Paste the key and tap Save key. Kwil checks it with Anthropic, stores it encrypted, and from then on shows only its last four characters.

Keeping it safe

Treat the key like a password: don't post it or send it in a chat. If you think someone else has it, delete it in the console under API keys and make a new one. To stop Kwil using it, choose Remove key in Settings, or delete the key in the console.

More about what Kwil stores is on the privacy page.
